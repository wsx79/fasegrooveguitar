# Roadmap

*🇮🇹 [Versione italiana](ROADMAP.it.md)*

Ideas for the next versions of **Fase Groove Guitar**, step by step. When one ships, it moves to
the [CHANGELOG](CHANGELOG.md).

- More grooves per genre, refined by ear.
- LINK the chords too: the guitar follows Fase Groove Piano's chords without routing MIDI.
- More voicings per lane (higher positions, inversions) and a chord per half bar.
- More guide guitar sounds (an overdriven funk, a twelve-string).
